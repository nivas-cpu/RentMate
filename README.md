# RentMate: Find the Home You’ll Actually Love 🏠✨

Finding a place to live shouldn't feel like a part-time job. Whether you're hunting for a cozy studio or looking for a housemate who won't leave their dishes in the sink, **RentMate** is here to make the journey a little bit smoother and a lot more beautiful.

---

## Why RentMate?
Most rental sites are cluttered and cold. We built RentMate with a "human-first" approach:
- **It’s Moody (in a good way):** Toggle between a crisp Light Mode and a deep, premium Dark Mode depending on your vibe.
- **Smooth Moves:** Every page transition and card interaction is powered by Framer Motion, making the app feel alive and responsive.
- **Real Connections:** Our built-in messaging system lets you talk to people, not just "listings."
- **Find what's near you:** Use our "Near Me" feature with interactive Leaflet maps to find hidden gems in your favorite neighborhood.

---

## ✨ Features that Make a Difference

### 🏘️ Smart Property Discovery
Verified homes across India's top cities. Filter by price, type, and location to find exactly what you're looking for.

### 👥 Roommate Matchmaking
Search for housemates who share your interests, lifestyle, and budget. No more awkward "getting to know you" phases when the rent is due.

### 🗺️ Live Maps & Address Magic
Powered by OpenStreetMap. Get address suggestions as you type and see exactly where your next home is on our interactive maps.

### 🛡️ Secure & Simple Access
Log in securely with just your email—powered by Supabase. No complex passwords to forget.

---

## 🛠️ The Tech Under the Hood
We used a modern stack to keep things fast and reliable:
- **Frontend:** React (powered by Vite)
- **Styling:** Tailwind CSS (for that sleek, responsive look)
- **Animations:** Framer Motion (for that premium "oomph")
- **Database & Auth:** Supabase (keeping your data safe)
- **Maps:** Leaflet & Nominatim (finding your way)

## 🚀 Let's Get You Started

Want to see it in action? It takes less than a minute.

1. **Grab the code**
   ```bash
   git clone https://github.com/nivas-cpu/RentMate.git
   ```

2. **Fuel it up**
   ```bash
   npm install
   ```

3. **Ignition**
   ```bash
   npm run dev
   ```

4. **Visit**
   Open [http://localhost:5173](http://localhost:5173) and start finding your next home.
